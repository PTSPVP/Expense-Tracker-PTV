# สมุดรายรับรายจ่าย

เว็บจดรายรับรายจ่ายไฟล์เดียว (`index.html`) ไม่ต้องใช้เซิร์ฟเวอร์ ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้

## อัปโหลดขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `expense-tracker`)
2. กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดขึ้นไปพร้อมกัน (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`) จากนั้นกด **Commit changes** ไฟล์ต้องอยู่โฟลเดอร์เดียวกันทั้งหมด
3. ไปที่ **Settings → Pages**
4. ใต้ **Build and deployment** เลือก Source เป็น **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/expense-tracker/`

## ใช้งานบนมือถือ

เปิดลิงก์ในมือถือ แล้วเลือก "เพิ่มไปยังหน้าจอหลัก" จะใช้งานเหมือนแอป

## หมายเหตุ

- ข้อมูลอยู่ในเบราว์เซอร์แต่ละเครื่อง ใช้ปุ่ม "สำรองข้อมูล" เป็นระยะ และ "นำเข้าข้อมูลสำรอง" เมื่อย้ายเครื่อง
- แจ้งเตือนในเว็บทำงานเมื่อเปิดหน้าเว็บค้างไว้ หากต้องการเตือนแม้ปิดเว็บ ให้ใช้ปุ่ม "เพิ่มเตือนลงปฏิทินมือถือ"
